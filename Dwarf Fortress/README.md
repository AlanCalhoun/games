# Dwarf Fortress

Mods for the Steam release of Dwarf Fortress. They expect [DFHack](https://github.com/DFHack/dfhack).

## Mods

| Mod | Version | What it is |
|-----|---------|------------|
| [Malphar's No Fun Cheat Mod](./malphars-no-fun-cheat-mod) | 1.4.0 | God-mode dwarves, adamantine placement, a cheat workshop, and standing supplies. For when you don't want to have any fun. |
